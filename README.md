# TIMETT ⏰

**TIMETT** is a highly visualistic, interactive, and modern timetable and schedule management application designed to make daily time-blocking and routine organization smooth, clean, and visually delightful.

---

## ✨ Key Visual Features

* **Dynamic Timeline Grid:** Move away from boring static rows. Enjoy proportional time blocks with smooth rounded corners and color-coded categorizations.
* **Real-time Progress Indicator:** A live glowing timeline tracker showing exactly where you are in your current day.
* **Conflict & Overlap Alerts:** Intelligent layout updates that detect and highlight overlapping time slots or back-to-back crunches.
* **Fluid Micro-interactions:** Powered by Framer Motion for silky smooth transitions, card elevation on hover, and delightful state changes.
* **Dark Mode Native:** Designed from the ground up to make vibrant category colors pop against a gorgeous dark theme canvas.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React

---

## 🚀 Getting Started Locally

Follow these steps to get the development environment running on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/1pruthvik/TIMETT.git
   cd TIMETT
   ```

2. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open the app:**
   Open http://localhost:3000 in your browser to view the timetable application.
